# 0.1.0 — 2026-09-29

Initial release. 12 original spinners, dependency-free:

- orbit, ring, dual-ring, pulse-ring, comet, bars
- dots, typing, grid, morph, flip, progress
- CSS-variable theming (`--ok-size`, `--ok-color`, `--ok-speed`)
- `prefers-reduced-motion` support
- Per-spinner imports via `orbitkit/spinners/<name>`
- Interactive demo page with live playground
